Day1부터 Day8까지의 문법과 알고리즘을 분석하여 아래의 명령을 실행해줘.

목적 : 기본적인 방명록 앱을 구현
규칙 :
폴더 내의 기술 스택을 최대한 유지하면서 필요한 라이브러리나 알고리즘은 사용자에게 물어보고 진행
최소한의 최소한의 화면으로 구성하되, 복잡한 기술 요소는 사용하지 않는다.(React.js, view.js, javascript 등)
html위주로 구현. 꼭 필요한 경우마다 제한적으로 필요한 라이브러리 등을 사용
데이터베이스는 python 내장 데이터베이스를 사용하고 테이블 구조는 간단하게 구성
테이블은 한 개만 사용하고 다른 요소와 릴레이션 관계를 갖지 않음

무료 배포 사이트에 배포하는 것을 전제로 작성하기 때문에
무료의 범위를 넘어서는 분량이나 기타 기술 요소는 사용하지 않도록 점검해야함
