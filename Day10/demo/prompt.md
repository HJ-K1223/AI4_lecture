# 프로젝트명 : note-demo
기능 :
    1. 회원 가입 --> 향후 sns 로그인으로 대체
        이메일 주소 
        이름(닉네임)
        비밀번호 --> 향후 암호화
    2. 로그인
    3. 로그아웃
    4. 비밀번호 찾기 --> 향후 / 현재는 mock-up만 제공
    5. 게시판
        제목과 내용으로 구성, 목록 조회는 제목만
        5-1. 페이징으로 조회(한 페이지에 기본 글 10개 제공)
        5-2. 상세 내용 확인
        5-3. 자기 글은 삭제/수정 가능
        5-4. 댓글 기능
        5-5. 불쾌한 표현은 키워드 매핑 or 정규식 형태로 찾아 마스킹 처리
            5-5-1. 불쾌한 표현은 인터넷 등 최신 정보를 찾아 최초 구성하고 관리자가 추가 및 삭제할 수 있게 구성
