사전의 정의문·예문·목록을 내려받아 복제하지 않고, 일반적인 단어 두 개만 독립적으로 선정했습니다. 공개 사전 본문은 사이트에 표시된 CC BY-SA 및 추가 이용 조건의 적용 대상입니다. 향후 본문이나 목록을 재사용한다면 해당 시점의 라이선스, 저작자 표시와 동일조건변경허락 요건을 별도로 확인해야 합니다.

이 목록은 최신 유행어를 포괄하거나 전문 검수를 거친 운영용 목록이 아닙니다. 단어의 문맥을 판정하지 않아 인용·교육·사전적 사용도 가려질 수 있습니다. 특정 집단 이름이나 중립적 단어를 금칙어로 추가하지 않았습니다. 띄어쓰기·특수문자 삽입 우회는 지원하지 않습니다.

`python manage.py load_banned_terms seeds/banned_terms.json`을 명시적으로 실행할 때만 등록됩니다. 반복 실행 시 같은 규칙은 건너뛰지만, 관리자가 삭제한 규칙도 이 명령을 다시 실행하면 다시 등록됩니다. 시작/배포 스크립트에 자동 로딩을 넣지 마세요. 규칙은 관리자 화면에서 추가·삭제하며 총 500개를 넘길 수 없습니다.
