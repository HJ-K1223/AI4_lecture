현재 폴더의 main.py와 probe.py를 읽고 성능 문제를 분석해줘.
나는 FastAPI 비동기를 배우는 비전공자야.

[실행 조건]
python -m uvicorn main:app --port 8000
기본 단일 worker로 실행하고, 다른 터미널에서 python probe.py를 실행했어.

[증상]
요청 하나는 /bad와 /good 모두 약 2초야.
요청 세 개를 함께 보내면 /bad 전체는 약 6초, /good 전체는 약 2초야.
HTTP 응답은 모두 200이고 오류 메시지는 없어.
위 수치는 기대 예시이므로 실제 실행 결과가 있으면 실제 측정값을 우선해줘.

[요청]
1. 아직 파일을 수정하지 말고 원인 후보와 확인 방법부터 알려줘.
2. /bad에서 호출하는 보조 함수 내부까지 추적해줘.
3. 어느 코드가 어느 스레드의 진행을 막는지 코드 근거로 설명해줘.
4. 클라이언트가 실제로 요청 세 개를 함께 시작하는지도 확인해줘.
5. 직접 실행한 사실과 코드만 보고 추론한 내용을 구분해줘.
6. 원인과 해결 방향을 카페 주문에 비유해 설명해줘.
