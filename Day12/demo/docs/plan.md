## 수정 가정

- 비회원 장바구니 저장·병합을 생략하여 테이블을 5개로 줄입니다. 비회원의 선택 상품·수량은 next URL로 유지합니다. 로그인 후 화면으로 돌아와 사용자가 작업을 계속합니다.
- 통화는 KRW, 모의 카드 결제 한 종류입니다. 배송비·할인·환불은 추가하지 않습니다.
- 상품당 수량 1~99개, 목록은 페이지당 12개·최신 등록순입니다.
- 이메일은 소문자로 정규화하며 자체 회원 인증을 사용합니다. 이메일 인증·비밀번호 찾기·관리자·검색·리뷰는 추가하지 않습니다.
- 주문 화면은 회원 이름·전화·주소를 기본값으로 표시하고 필수 배송정보를 입력받아 해당 주문에 복사합니다. 입력값은 회원정보를 덮어쓰지 않습니다.

## 유지하는 요구사항

- Python 3.11+ / FastAPI / Uvicorn / Supabase PostgreSQL
- Jinja2 / HTML / 직접 작성한 CSS / Vanilla JavaScript, Node·npm·프론트 프레임워크 미사용
- Mobile First, 360px / 768px / 1280px에서 점검
- 서버에서 SQLAlchemy·psycopg로 DB 연결, 비밀값은 환경변수 관리
- Argon2 해시, 만료되는 서명 세션, HttpOnly·Secure·SameSite=Lax 쿠키
- CSRF 토큰과 Origin/Referer 검사, GET으로 상태 변경 금지
- next는 내부 상대경로만 허용, 외부 도메인·//·역슬래시·제어문자·인코딩 우회 차단
- 인증 필요 HTML은 로그인으로 이동, 공통 fetch는 401 시 현재 내부 URL을 next로 전달
- 개인 데이터의 회원 소유권 검사, Pydantic 검증·매개변수 바인딩
- 로그인 복귀 후 자동 결제하지 않음, 결제 완료 후 상품 목록 이동
- 로컬 HTTP에서만 Secure 쿠키 개발 예외 허용, 운영에서는 Secure 필수
